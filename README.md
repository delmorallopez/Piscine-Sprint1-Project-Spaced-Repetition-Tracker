[https://piscine-sprint1-project-spaced-repeti.netlify.app/]

## Description

A tool for tracking spaced repetition learning intervals. Review topics after 1 week, 1 month, 3 months, 6 months, and 1 year from the start date.

## Features

- Select from 5 different users
- Add new topics with start dates
- Automatic calculation of revision intervals
- Agenda display showing future revision dates in chronological order
- Data persistence using localStorage
- 100% accessibility score

## Technology Stack

- HTML5
- JavaScript (ES6 modules)
- No CSS (as per project requirements)

## Installation & Running Locally

```bash
# Clone the repository
git clone https://github.com/delmorallopez/Piscine-Sprint1-Project-Spaced-Repetition-Tracker
cd Piscine-Sprint1-Project-Spaced-Repetition-Tracker


# Install dependencies
npm install

# Start the development server
npm start

# Open http://localhost:8081 in your browser
```
